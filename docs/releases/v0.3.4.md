# GreenVita v0.3.4 Final

## English

This release returns to the Public decoder configuration tested on physical PS Vita in Build 18, with the log cleanup introduced in Build 19 and release fixes. Later latency experiments are not included.

- Single-output Public H.264 decoder, three BGR565 textures, original SPS and 64-byte zeroed input padding inspired by VitaPlus and Moonlight.
- Accurate correlation to the picture PTS returned by the decoder, detailed buffering diagnostics and a 60-second benchmark.
- Proactive decoder restart removed after Build 22 showed worse latency. Genuine error/resync recovery remains. No internal Low Delay backend or Moonlight initialization hint.
- Automatic removal of old build logs after the current log is successfully written; current and rotated logs remain bounded. Settings and credentials are preserved.
- Update notification uses the installed package version; no automatic VPK installation.
- Existing Extreme synchronization, Gamepad RAW, audio and image settings remain unchanged.

Build 18 physical reference: 90.14 ms mean, 60.31 ms minimum, 96.29 ms P95, 58.75 presentations/s in the first 60-second benchmark; 102.53 ms mean and 59.55 presentations/s in the second. These are local client pipeline measurements including matched decoder residence, not button-to-photon or physical scanout. Earlier versions measured different stages; direct comparisons are not valid. The final VPK is rebuilt with the release corrections and has not been independently benchmarked on hardware. Log cleanup itself was verified on Build 22 (four files removed, zero failures).

Install `green-vita.vpk` using VitaShell with Unsafe Homebrew enabled. Existing title ID GREENVITA is retained. Current log: `ux0:data/xcloud-rust/connection-status-b034.txt`. Previous stable release v0.3.3 remains available. Cloud gameplay tested on Vita; local console streaming and every game/network are not independently validated.

## Português (Brasil)

Esta versão retorna à configuração Public da Build 18, testada em um PS Vita real, com a limpeza de logs da Build 19 e correções de publicação. Os experimentos posteriores de latência não foram incluídos.

- Decoder Public H.264 com saída única, três texturas BGR565, SPS original e proteção de 64 bytes zerados no buffer de entrada, inspirada no VitaPlus e Moonlight.
- Medição pelo PTS da imagem efetivamente devolvida, diagnóstico de buffering e benchmark de 60 segundos.
- Remoção da reinicialização preventiva após a regressão da Build 22; recuperação real de erros e ressincronização mantidas. Sem decoder interno Low Delay nem ajuste de inicialização do Moonlight.
- Limpeza automática de logs antigos após gravação bem-sucedida do log atual. Mantém o atual e o anterior rotacionado, preservando configurações e credenciais.
- Aviso de atualização corrigido para utilizar a versão instalada, sem instalação automática.
- Sincronização Extreme, Gamepad RAW, imagem e áudio preservados.

Referência física da Build 18: média de 90,14 ms, mínimo de 60,31 ms, P95 de 96,29 ms e 58,75 apresentações/s no primeiro benchmark de 60 segundos; média de 102,53 ms e 59,55 apresentações/s no segundo. A medição inclui a permanência no decoder; não é latência total do botão à tela. Versões anteriores mediam etapas diferentes, portanto não são diretamente comparáveis. O VPK final será recompilado com as correções e ainda não possui benchmark próprio no hardware. A limpeza de logs foi validada na Build 22 (quatro removidos, zero falhas).

Instale `green-vita.vpk` pelo VitaShell, com Unsafe Homebrew ativado. O Title ID GREENVITA permanece. Log: `ux0:data/xcloud-rust/connection-status-b034.txt`. A v0.3.3 continua disponível para retorno. Testes de cloud gaming em Vita real; streaming local de console e todos os jogos/redes não foram validados de forma independente.
