# GreenVita v0.4.1 Beta — Xbox GSSV Regional Host Recovery
# GreenVita v0.4.1 Beta — Correção de host/região Xbox

## Português (Brasil)

**Hotfix da v0.4.0.** Corrige um problema reportado em hardware real: o Xbox Cloud Gaming pode retornar HTTP **400 Bad Request** com **"Unexpected host format or region"** ao iniciar a transmissão. Um caso reproduzido na comunidade mostrou host `brs.core.gssv-play-prod.xboxlive.com` e núcleo `ASIAPACIFIC`.

### Correção
- Quando o erro de incompatibilidade entre host e núcleo regional é detectado, o GreenVita tenta novamente **apenas URLs HTTPS das regiões devolvidas no mesmo token Microsoft**.
- Prioriza regiões que correspondem à indicação do servidor; preserva a região salva pelo usuário quando não existe erro.
- Limita as tentativas alternativas a **quatro** para streaming normal e **duas** para a oferta experimental de console.
- Mantém o token isolado por oferta, inclusive o cabeçalho de dispositivo correto para `xgpuconsole`.
- Não tenta contornar `OfferingDoesNotContainTitle`, proibições de dispositivo, ausência de autorização ou falhas de rede; tais erros continuam visíveis.
- Adiciona testes de regressão contra uso de domínios externos e detecção incorreta de HTTP 400.
- Caso não existam regiões alternativas aceitas, mostra instruções para renovar login e restaurar a região padrão.

### Importante
A compilação bem-sucedida **não garante** que a Microsoft oferecerá uma região compatível. O problema ocorre **antes** da sessão WebRTC e é independente do decodificador H.264. Erros de **Xbox Remote Play / WebRTC Session Failed** reportados por outros testadores precisam de registros ICE/SDP específicos para diagnóstico e não são considerados corrigidos por este hotfix.

A versão preserva o motor de streaming RTX/TWCC do Michael, os perfis 6/10/15 Mbps, xHome, áudio adaptativo e 19 idiomas da v0.4.0.

**Teste:** instalar o VPK, entrar no Xbox Cloud Gaming, iniciar um jogo que já apareça na biblioteca e registrar se a sessão ultrapassa o estágio de provisionamento. Se o erro persistir, comparar com a região padrão nas Configurações e refazer login. Nunca publique tokens ou URLs contendo credenciais.

## English

**v0.4.0 hotfix.** Addresses a real-device report where Xbox Cloud Gaming stream startup returned **HTTP 400 Bad Request — "Unexpected host format or region"**. The reported gateway used `brs.core.gssv-play-prod.xboxlive.com` with backend core `ASIAPACIFIC`.

### Fix
- Only after this specific error, retry a bounded set of alternative HTTPS Xbox region hosts **explicitly listed by Microsoft's token response**.
- Prefer server-core-compatible regions when available. Preserve the saved region when it works.
- Maximum four alternate endpoints for regular streaming and two for experimental console-offering sessions.
- Keep tokens scoped to their original offering and retain `xgpuconsole` device headers on any authorized retry.
- Do **not** mask game eligibility, authorization, unsupported devices or general HTTP failures.
- Added regression tests for routing error classification and origin allowlisting.
- Explain actionable account/region recovery if no approved alternative succeeds.

**Note:** A successful build cannot guarantee a compatible Microsoft region is available. The reported error occurs **before WebRTC negotiation**. Separate Xbox Remote Play failures (e.g. "WebRTC session failed") require ICE/SDP diagnostics and are **not claimed fixed** by this patch.

Retains Michael's RTX/TWCC/H.264 decoding improvements, 6/10/15 Mbps profiles, xHome features, adaptive audio and 19 languages.

**Testing:** Install via VitaShell; try an eligible xCloud title and check whether the session progresses beyond provisioning. Try the default region and refreshing Xbox login if all approved hosts fail. Never share authentication tokens.
