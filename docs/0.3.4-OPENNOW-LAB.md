# GreenVita 0.3.4 OpenNOW Lab

Experimental branch only. No release, no stable tag changes. Base: v0.3.3-final 056df51d56174f25b1407b70d53fecee8e9b62a0. References: OpenCloudGaming/OpenNOW-vita (f133d2556b7ba2e09880eb534dc5a24306cef987), MPL-2.0 notices included.

- Fat LTO and one codegen unit; Rust unwind recovery retained.
- Three direct textures when available, with two-texture fallback. Pending frames only replaced after completed decode when a free target exists. Single pending picture, no added FIFO; compressed H264 ordering retained.
- Public hardware AVCDEC only. Internal Low Delay backend, private imports, special build script and settings selector removed after hardware testing. The public decoder and worker retain their original 0.3.3 timing convention, which does not independently establish the actual age of a buffered picture.
- Optional tightly validated NV12, BGR565 default, IYUV allocation fallback when advertised by SDL. YUV color conversion and hardware behavior require physical testing. No claim of faster decode.
- Dedicated Opus/SDL thread with per-session bounded channel; PLC for at most two timestamp-confirmed lost packets using actual preceding duration. RED is not negotiated by Xbox; no NVIDIA-specific payload assumptions. Adaptive buffer targets, gain 100/125/150% peak-limited.
- Render/input/audio affinity in addition to existing network/decoder affinity. Optional session-scoped clocks (444/222/222/166 MHz requests) restore previous queried frequencies on exit/interruption when possible. Defaults off.
- Live-video watchdog PLI at 4 s, reconnect at 8 s once live; warm-start bitrate hint from five healthy samples per profile, persisted on session exit, bounded to +2 Mbps; never limits adaptive growth.
- 60-second benchmark preserved. Actual decoder and texture count/format shown on benchmark HUD/log. Test 0.3.3 versus 0.3.4 on same game/network/profile, clocks off and BGR565 first. Then compare two vs three textures, optional NV12 and clocks separately. Check sound, artifacts, disconnect, pause, resume, battery, and log. CPU-side latency excludes scanout, network and server. Build 2 has been tested on a physical Vita; the removal build still requires validation.

The internal path used returned picture timestamps while the public path uses the current submission timestamp. These measurements are not a controlled end-to-end comparison; the large regression provides no reason to retain the private backend in the current experimental package. Historical code remains in Git. Tester reports very good audio across all four tests, so audio code is unchanged. NV12 appeared washed out; it remains optional and BGR565 remains the default, with no unvalidated color correction in this build. Existing saved NV12 selection is retained. Pending comparison: public decoder, two BGR565 textures, clocks off, same workload/profile/network. No release publication.

## Startup authentication resilience (build 4)
User reported occasional token errors on launch that recover after Back, which restarts credential loading. No error code was supplied; the failing endpoint is not confirmed. Critical startup exchanges retry transient connect/timeout errors and HTTP 408/429/500/502/503/504 up to twice with bounded backoff; Retry-After is respected or retries stop if it cannot be safely interpreted. No retry on actual authentication/authorization refusals. Optional console/F2P probes do not add retries. OAuth response without a replacement refresh token retains the existing saved value. Form credentials are percent-encoded. Profile loading reuses the Xbox user token instead of rotating the saved Microsoft refresh token again and remains nonessential. Redacted diagnostics identify recovery/failure stages. Genuine invalid_grant still requires sign-in. Existing AES vault and streaming/audio/control policies unchanged. Physical startup verification pending.
